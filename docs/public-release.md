# 公开发布边界

发布树只包含自主维护技术代码、重新编写的通用技术模板、虚构测试、配置占位示例、架构/部署说明，以及上游版本和依赖锁定。

不导入原项目 Git 历史。历史开发记录、生产操作证据、角色卡、原始提示词、实际模型网关/模型选择、服务器用户名和路径、账号和真实UID、真实样例、聊天与人物资料、数据库、备份、密钥、模型权重及第三方下载包均不发布。

提示词脱敏覆盖默认提示、内嵌的记忆/偏好抽取、归属与连续性修订、模型协议修复、公开内容生成和工具说明。公开模板只描述接口契约、来源限制、输出格式及权限边界，不含私人角色或个人设定。协议字段如 `MEMORY_DATA_JSON`、`tool_calls` 与 generation 是技术接口，需保留以维持安全边界。

测试中的称呼、账号和对话是虚构资料。必要的凭据格式样例仅用于验证拒绝与脱敏；不能用作认证。真实联调需要部署者显式提供自己的配置，输出报告默认被忽略。

`scripts/audit_public.py` 检查候选或已跟踪文件名、主机路径、凭据模式和意外运行数据；它不输出匹配值。自动检查不能证明未来任意修改均无隐私，新增样例和提示词仍需人工审阅。

发布验证的实际范围记录在 `docs/validation.md`；未运行的真实模型、图服务、镜像或线上验证不宣称通过。
